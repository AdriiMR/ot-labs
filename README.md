# OT-Labs

[🇪🇸 Leer en español](README.es.md)

**OT-Labs** is a personal hands-on learning project focused on operational technology (OT) systems and industrial cybersecurity.

Its purpose is to build and explore simulated industrial environments to understand how they operate, how their components communicate, and the security risks associated with them.

The project is developed through documented practical labs, with the aim of making the scenarios reproducible and sharing the knowledge gained along the way.

## 1. Objectives

- Understand how industrial systems and their components work.
- Become familiar with the protocols and communications used in OT environments.
- Build virtualized environments to experiment with industrial processes.
- Progressively explore security risks and protective measures applicable to these systems.
- Document procedures and findings to make the labs easier to reproduce.

## 3. Responsible Use

The labs in **OT-Labs** are intended exclusively for educational and research purposes in controlled environments.

The configurations, tools, and procedures described must only be used on systems you own or have explicit authorization to work with.

This project is not intended for direct deployment in production industrial environments.
